## Задача 1.3. Визначте час виконання фрагментів програм

Кожен рядок (присвоєння, арифметична дія, перевірка умови циклу) вважаємо елементарною операцією вартістю 1. Умова циклу `while` перевіряється на один раз більше, ніж виконується тіло циклу.

### a)
```python
1   k += 1
2   i = n
3   while i > 0:
4       i -= 1
```
Рядки 1, 2 виконуються по 1 разу. Тіло циклу виконується n разів (i = n, n−1, …, 1), умова перевіряється n + 1 раз.

**T(n) = 1 + 1 + (n + 1) + n = 2n + 3 = O(n).**

### b)
```python
1   i = n
2   while i > 1:
3       k += 1
4       i //= 2
```
Після кожної ітерації i зменшується вдвічі. Цикл зупиняється, коли i ≤ 1, тобто кількість ітерацій m = ⌊log₂ n⌋.
Рядок 1 виконується 1 раз, рядок 2 — m + 1 раз, рядки 3, 4 — по m разів.

**T(n) = 1 + (m + 1) + 2m = 3⌊log₂ n⌋ + 2 = O(log n).**

### d)
```python
1   i = 0
2   while i < n:
3       j = 0
4       while j < i * i:
5           k += 1
6           j += 1
7       i += 1
```
Для фіксованого i внутрішній цикл виконується i² разів, отже рядок 4 виконується i² + 1 раз, рядки 5, 6 — по i² разів. Одна ітерація зовнішнього циклу: 1 + (i² + 1) + 2i² + 1 = 3i² + 3.

T(n) = 1 + (n + 1) + Σ_{i=0}^{n−1} (3i² + 3) = n + 2 + 3n + 3·(n−1)n(2n−1)/6.

**T(n) = n³ − 3/2·n² + 9/2·n + 2 = O(n³).**

Перевірка: n = 1 → 1 − 1,5 + 4,5 + 2 = 6.

### e)
```python
1   i = 1
2   while i < n:
3       j = 1
4       while j < n:
5           k += 1
6           j *= 2
7       i *= 2
```
i пробігає значення 1, 2, 4, …, менші за n; їх p = ⌈log₂ n⌉. Внутрішній цикл від i не залежить і теж має p ітерацій.
Одна ітерація зовнішнього циклу: 1 + (p + 1) + 2p + 1 = 3p + 3.

T(n) = 1 + (p + 1) + p(3p + 3).

**T(n) = 3p² + 4p + 2, де p = ⌈log₂ n⌉; T(n) = O(log² n).**

Перевірка: n = 2 → p = 1, T = 9.

## Задача 1.4. Визначте час виконання програми у явному вигляді за рекурентним співвідношенням

### a) T(n) = 1 при n ≤ a (a > 0); T(n) = T(n − a) + 1 при n > a
T(n) = T(n − a) + 1 = T(n − 2a) + 2 = … = T(n − ka) + k.
Зупиняємося при першому k, для якого n − ka ≤ a, тобто k = ⌈n/a⌉ − 1. Тоді

**T(n) = 1 + ⌈n/a⌉ − 1 = ⌈n/a⌉ (n > 0); T(n) = O(n/a).**

### b) T(0) = 1; T(n) = T(n − 1) + 2ⁿ
T(n) = T(0) + 2¹ + 2² + … + 2ⁿ = 1 + 2 + 4 + … + 2ⁿ (геометрична прогресія).

**T(n) = 2ⁿ⁺¹ − 1 = O(2ⁿ).**

### c) T(1) = 1; T(n) = 2T(⌊n/2⌋) + 1
Нехай k = ⌊log₂ n⌋. Розкриваємо k разів:
T(n) = 2T(n/2) + 1 = 4T(n/4) + 2 + 1 = … = 2ᵏ·T(1) + (2ᵏ⁻¹ + … + 2 + 1) = 2ᵏ + 2ᵏ − 1.

**T(n) = 2^(⌊log₂ n⌋ + 1) − 1; для n = 2ᵏ: T(n) = 2n − 1. T(n) = O(n).**

## Задача 2.10

```python
def f(n):
    sum = 0
    for i in range(1, n + 1):
        sum = sum + i
    return sum
```
* Цикл виконується n разів, тіло — O(1), тому час у найгіршому випадку **O(n)**.
* Результат: **f(n) = 1 + 2 + … + n = n(n + 1)/2**.
* Функцію можна оптимізувати, обчисливши суму за формулою арифметичної прогресії. Асимптотика покращується до **O(1)**:

```python
def f_fast(n):
    return n * (n + 1) // 2
```

## Задача 2.13. Знайдіть асимптотичний час виконання програми за рекурентним співвідношенням

### a) T(0) = O(1); T(n) = T(n − 1) + O(1)
Нехай O(1) ≤ c. Тоді T(n) ≤ T(n − 1) + c ≤ T(n − 2) + 2c ≤ … ≤ T(0) + nc ≤ c(n + 1).

**T(n) = O(n).**

### e) T(0) = O(1); T(n) = T(n − 1) + O(n)
Нехай доданок O(n) ≤ cn. Тоді
T(n) ≤ T(0) + c(1 + 2 + … + n) = T(0) + c·n(n + 1)/2.

**T(n) = O(n²).**

### g) T(1) = O(1); T(n) = aT(⌊n/a⌋) + O(1), a ≥ 2
Нехай n = aᵏ (k = log_a n), O(1) ≤ c. Розкриваємо:
T(n) ≤ aT(n/a) + c ≤ a²T(n/a²) + ac + c ≤ … ≤ aᵏT(1) + c(1 + a + … + aᵏ⁻¹)
= c·aᵏ + c·(aᵏ − 1)/(a − 1) ≤ c·n·(1 + 1/(a − 1)).

**T(n) = O(n).**

## Задача 2.14. Доведіть співвідношення

Для доведення пропонуємо алгоритм обчислення лівої частини з вказаною асимптотикою. Арифметичні операції вважаємо елементарними (O(1)).

| | Вираз | Алгоритм | Час |
|---|---|---|---|
| a) | Σ_{i=0}^{n} i | один цикл, на кожному кроці `s += i` | n + 1 ітерацій по O(1) → **O(n)** |
| b) | Σ_{i=0}^{n} i² | один цикл, `s += i * i` | **O(n)** |
| c) | Σ_{i=0}^{n} aⁱ | степінь не обчислюємо заново: `p *= a` після кожного кроку (aⁱ = aⁱ⁻¹·a) | **O(n)** |
| d) | Σ_{i=0}^{n} iⁱ | iⁱ обчислюємо внутрішнім циклом з i множень | 0 + 1 + … + n = n(n+1)/2 множень → **O(n²)** |
| e) | Π_{i=1}^{n} 1/(1+i) | один цикл, `r /= 1 + i` | **O(n)** |
| f) | Π_{i=1}^{n} 1/(1+i!) | факторіал оновлюємо на кожному кроці: `fact *= i` (i! = (i−1)!·i) | **O(n)** |
| g) | Π_{i=1}^{n} aⁱ/(1+i!) | одночасно оновлюємо `p *= a` та `fact *= i`, `r *= p / (1 + fact)` | **O(n)** |
| h) | Π_{i=1}^{n} 1/(1+iᵐ) | iᵐ — внутрішній цикл з m множень | n·m множень → **O(nm)** |
| i) | Π_{i=1}^{n} 1/(1+iⁱ) | iⁱ — внутрішній цикл з i множень | n(n+1)/2 множень → **O(n²)** |

Приклад (c):
```python
def sum_c(n, a):
    s, p = 0, 1
    for i in range(n + 1):   # n + 1 ітерацій
        s += p               # p = a^i
        p *= a               # a^(i+1) за одне множення
    return s
```
Приклад (i):
```python
def prod_i(n):
    r = 1.0
    for i in range(1, n + 1):      # n ітерацій
        p = 1.0
        for _ in range(i):         # i множень
            p *= i
        r /= 1 + p
    return r                       # усього 1 + 2 + ... + n = O(n^2) множень
```
